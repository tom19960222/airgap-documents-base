## [Plugin Index](index.md#id2)

These are the plugins in the community.google collection:

### Modules

- [gc_storage module](gc_storage_module.md#ansible-collections-community-google-gc-storage-module) – This module manages objects/buckets in Google Cloud Storage.
- [gce_eip module](gce_eip_module.md#ansible-collections-community-google-gce-eip-module) – Create or Destroy Global or Regional External IP addresses.
- [gce_img module](gce_img_module.md#ansible-collections-community-google-gce-img-module) – utilize GCE image resources
- [gce_instance_template module](gce_instance_template_module.md#ansible-collections-community-google-gce-instance-template-module) – create or destroy instance templates of Compute Engine of GCP.
- [gce_labels module](gce_labels_module.md#ansible-collections-community-google-gce-labels-module) – Create, Update or Destroy GCE Labels.
- [gce_lb module](gce_lb_module.md#ansible-collections-community-google-gce-lb-module) – create/destroy GCE load-balancer resources
- [gce_mig module](gce_mig_module.md#ansible-collections-community-google-gce-mig-module) – Create, Update or Destroy a Managed Instance Group (MIG).
- [gce_net module](gce_net_module.md#ansible-collections-community-google-gce-net-module) – create/destroy GCE networks and firewall rules
- [gce_pd module](gce_pd_module.md#ansible-collections-community-google-gce-pd-module) – utilize GCE persistent disk resources
- [gce_snapshot module](gce_snapshot_module.md#ansible-collections-community-google-gce-snapshot-module) – Create or destroy snapshots for GCE storage volumes
- [gce_tag module](gce_tag_module.md#ansible-collections-community-google-gce-tag-module) – add or remove tag(s) to/from GCE instances
- [gcpubsub module](gcpubsub_module.md#ansible-collections-community-google-gcpubsub-module) – Create and Delete Topics/Subscriptions, Publish and pull messages on PubSub
- [gcpubsub_info module](gcpubsub_info_module.md#ansible-collections-community-google-gcpubsub-info-module) – List Topics/Subscriptions and Messages from Google PubSub.

### Lookup Plugins

- [gcp_storage_file lookup](gcp_storage_file_lookup.md#ansible-collections-community-google-gcp-storage-file-lookup) – Return GC Storage content
