## [Plugin Index](index.md#id2)

These are the plugins in the community.sap_libs collection:

### Modules

- [sap_company module](sap_company_module.md#ansible-collections-community-sap-libs-sap-company-module) – This module will manage a company entities in a SAP S4HANA environment
- [sap_control_exec module](sap_control_exec_module.md#ansible-collections-community-sap-libs-sap-control-exec-module) – Ansible Module to execute SAPCONTROL
- [sap_hdbsql module](sap_hdbsql_module.md#ansible-collections-community-sap-libs-sap-hdbsql-module) – Ansible Module to execute SQL on SAP HANA
- [sap_pyrfc module](sap_pyrfc_module.md#ansible-collections-community-sap-libs-sap-pyrfc-module) – Ansible Module for use of SAP PyRFC to execute SAP RFCs (Remote Function Calls) to SAP remote-enabled function modules
- [sap_snote module](sap_snote_module.md#ansible-collections-community-sap-libs-sap-snote-module) – This module will upload and (de)implements `SNOTES` in a SAP S4HANA environment.
- [sap_system_facts module](sap_system_facts_module.md#ansible-collections-community-sap-libs-sap-system-facts-module) – Gathers SAP facts in a host
- [sap_task_list_execute module](sap_task_list_execute_module.md#ansible-collections-community-sap-libs-sap-task-list-execute-module) – Perform SAP Task list execution
- [sap_user module](sap_user_module.md#ansible-collections-community-sap-libs-sap-user-module) – This module will manage a user entities in a SAP S4/HANA environment
- [sapcar_extract module](sapcar_extract_module.md#ansible-collections-community-sap-libs-sapcar-extract-module) – Manages SAP SAPCAR archives
