# community.fortios.fortianalyzer httpapi – HttpApi Plugin for Fortinet FortiAnalyzer Appliance or VM.

> **Note:**
>
> This httpapi plugin is part of the [community.fortios collection](https://galaxy.ansible.com/ui/repo/published/community/fortios/) (version 1.0.0).
>
> You might already have this collection installed if you are using the `ansible` package.
> It is not included in `ansible-core`.
> To check whether it is installed, run `ansible-galaxy collection list`.
>
> To install it, use: `ansible-galaxy collection install community.fortios`.
>
> To use it in a playbook, specify: `community.fortios.fortianalyzer`.

- [Synopsis](fortianalyzer_httpapi.md#synopsis)

## [Synopsis](fortianalyzer_httpapi.md#id1)

- This HttpApi plugin provides methods to connect to Fortinet FortiAnalyzer Appliance or VM via JSON RPC API.
