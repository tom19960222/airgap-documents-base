## [Synopsis](dynamodb_ttl_module.md#id1)

- Sets the TTL for a given DynamoDB table.

## [Requirements](dynamodb_ttl_module.md#id2)

The below requirements are needed on the host that executes this module.

- python >= 3.6
- boto3 >= 1.22.0
- botocore >= 1.25.0

## [Examples](dynamodb_ttl_module.md#id5)

```yaml+jinja
- name: enable TTL on my cowfacts table
  community.aws.dynamodb_ttl:
    state: enable
    table_name: cowfacts
    attribute_name: cow_deleted_date

- name: disable TTL on my cowfacts table
  community.aws.dynamodb_ttl:
    state: disable
    table_name: cowfacts
    attribute_name: cow_deleted_date
```
