## [Plugin Index](index.md#id2)

These are the plugins in the community.skydive collection:

### Modules

- [skydive_capture module](skydive_capture_module.md#ansible-collections-community-skydive-skydive-capture-module) – Module which manages flow capture on interfaces
- [skydive_edge module](skydive_edge_module.md#ansible-collections-community-skydive-skydive-edge-module) – Module to add edges to Skydive topology
- [skydive_node module](skydive_node_module.md#ansible-collections-community-skydive-skydive-node-module) – Module which add nodes to Skydive topology

### Lookup Plugins

- [skydive lookup](skydive_lookup.md#ansible-collections-community-skydive-skydive-lookup) – Query Skydive objects
