# community.network.ce cliconf – Use ce cliconf to run command on HUAWEI CloudEngine platform

> **Note:**
>
> This cliconf plugin is part of the [community.network collection](https://galaxy.ansible.com/ui/repo/published/community/network/) (version 5.0.2).
>
> You might already have this collection installed if you are using the `ansible` package.
> It is not included in `ansible-core`.
> To check whether it is installed, run `ansible-galaxy collection list`.
>
> To install it, use: `ansible-galaxy collection install community.network`.
>
> To use it in a playbook, specify: `community.network.ce`.

- [Synopsis](ce_cliconf.md#synopsis)

## [Synopsis](ce_cliconf.md#id1)

- This ce plugin provides low level abstraction apis for sending and receiving CLI commands from HUAWEI CloudEngine network devices.
