These are the plugins in the community.sap collection:

### Modules

- [database.saphana.hana_query module](database.saphana.hana_query_module.md#ansible-collections-community-sap-database-saphana-hana-query-module) – Execute SQL on HANA
- [files.sapcar_extract module](files.sapcar_extract_module.md#ansible-collections-community-sap-files-sapcar-extract-module) – Manages SAP SAPCAR archives
- [identity.sap_company module](identity.sap_company_module.md#ansible-collections-community-sap-identity-sap-company-module) – This module will manage a company entities in a SAP S4HANA environment
- [identity.sap_user module](identity.sap_user_module.md#ansible-collections-community-sap-identity-sap-user-module) – This module will manage a user entities in a SAP S4/HANA environment
- [system.sap_snote module](system.sap_snote_module.md#ansible-collections-community-sap-system-sap-snote-module) – This module will upload and (de)implements `SNOTES` in a SAP S4HANA environment.
- [system.sap_system_facts module](system.sap_system_facts_module.md#ansible-collections-community-sap-system-sap-system-facts-module) – Gathers SAP facts in a host
- [system.sap_task_list_execute module](system.sap_task_list_execute_module.md#ansible-collections-community-sap-system-sap-task-list-execute-module) – Perform SAP Task list execution
