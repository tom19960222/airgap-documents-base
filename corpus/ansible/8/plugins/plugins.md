# Working with plugins

Plugins are pieces of code that augment Ansible’s core functionality. Ansible uses a plugin architecture to enable a rich, flexible and expandable feature set.

Ansible ships with a number of handy plugins, and you can easily write your own.

This section covers the various types of plugins that are included with Ansible:

- [Action plugins](action.md)
- [Become plugins](become.md)
- [Cache plugins](cache.md)
- [Callback plugins](callback.md)
- [Cliconf plugins](cliconf.md)
- [Connection plugins](connection.md)
- [Docs fragments](docs_fragment.md)
- [Filter plugins](filter.md)
- [Httpapi plugins](httpapi.md)
- [Inventory plugins](inventory.md)
- [Lookup plugins](lookup.md)
- [Modules](module.md)
- [Module utilities](module_util.md)
- [Netconf plugins](netconf.md)
- [Shell plugins](shell.md)
- [Strategy plugins](strategy.md)
- [Terminal plugins](terminal.md)
- [Test plugins](test.md)
- [Vars plugins](vars.md)
