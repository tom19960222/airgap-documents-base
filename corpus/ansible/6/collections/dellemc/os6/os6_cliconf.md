# dellemc.os6.os6 cliconf – Use os6 cliconf to run command on Dell OS6 platform

> **Note:**
>
> This cliconf plugin is part of the [dellemc.os6 collection](https://galaxy.ansible.com/dellemc/os6) (version 1.0.7).
>
> You might already have this collection installed if you are using the `ansible` package.
> It is not included in `ansible-core`.
> To check whether it is installed, run `ansible-galaxy collection list`.
>
> To install it, use: `ansible-galaxy collection install dellemc.os6`.
>
> To use it in a playbook, specify: `dellemc.os6.os6`.

- [Synopsis](os6_cliconf.md#synopsis)

## [Synopsis](os6_cliconf.md#id1)

- This os6 plugin provides low level abstraction apis for sending and receiving CLI commands from Dell OS6 network devices.
