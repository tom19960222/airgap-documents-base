> **Note:**

> This cliconf plugin is part of the [dellemc.os9 collection](https://galaxy.ansible.com/dellemc/os9) (version 1.0.4).
>
> You might already have this collection installed if you are using the `ansible` package.
> It is not included in `ansible-core`.
> To check whether it is installed, run `ansible-galaxy collection list`.
>
> To install it, use: `ansible-galaxy collection install dellemc.os9`.
>
> To use it in a playbook, specify: `dellemc.os9.os9`.

## [Synopsis](os9_cliconf.md#id1)

- This os9 plugin provides low level abstraction apis for sending and receiving CLI commands from Dell OS9 network devices.
