## [Plugin Index](index.md#id2)

These are the plugins in the dellemc.os10 collection:

### Modules

- [base_xml_to_dict module](base_xml_to_dict_module.md#ansible-collections-dellemc-os10-base-xml-to-dict-module) – Operations for show command output convertion from xml to json format.
- [bgp_validate module](bgp_validate_module.md#ansible-collections-dellemc-os10-bgp-validate-module) – Validate the bgp neighbor state,raise error if it is not in established state
- [mtu_validate module](mtu_validate_module.md#ansible-collections-dellemc-os10-mtu-validate-module) – Validate the MTU value for lldp neighbors
- [os10_command module](os10_command_module.md#ansible-collections-dellemc-os10-os10-command-module) – Run commands on devices running Dell EMC SmartFabric OS10
- [os10_config module](os10_config_module.md#ansible-collections-dellemc-os10-os10-config-module) – Manage Dell EMC SmartFabric OS10 configuration sections
- [os10_facts module](os10_facts_module.md#ansible-collections-dellemc-os10-os10-facts-module) – Collect facts from devices running Dell EMC SmartFabric OS10
- [show_system_network_summary module](show_system_network_summary_module.md#ansible-collections-dellemc-os10-show-system-network-summary-module) – Operations for show_system_network output in json/yaml format.
- [vlt_validate module](vlt_validate_module.md#ansible-collections-dellemc-os10-vlt-validate-module) – Validate the vlt info, raise an error if peer is not in up state
- [wiring_validate module](wiring_validate_module.md#ansible-collections-dellemc-os10-wiring-validate-module) – Validate the wiring based on the planned wiring details

### Cliconf Plugins

- [os10 cliconf](os10_cliconf.md#ansible-collections-dellemc-os10-os10-cliconf) – Use os10 cliconf to run command on Dell OS10 platform
