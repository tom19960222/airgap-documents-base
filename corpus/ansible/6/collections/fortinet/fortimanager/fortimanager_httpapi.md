# fortinet.fortimanager.fortimanager httpapi – HttpApi Plugin for Fortinet FortiManager Appliance or VM.

> **Note:**
>
> This httpapi plugin is part of the [fortinet.fortimanager collection](https://galaxy.ansible.com/fortinet/fortimanager) (version 2.1.7).
>
> You might already have this collection installed if you are using the `ansible` package.
> It is not included in `ansible-core`.
> To check whether it is installed, run `ansible-galaxy collection list`.
>
> To install it, use: `ansible-galaxy collection install fortinet.fortimanager`.
>
> To use it in a playbook, specify: `fortinet.fortimanager.fortimanager`.

New in fortinet.fortimanager 2.8

- [Synopsis](fortimanager_httpapi.md#synopsis)

## [Synopsis](fortimanager_httpapi.md#id1)

- This HttpApi plugin provides methods to connect to Fortinet FortiManager Appliance or VM via JSON RPC API.
