# fortinet.fortios.fortios httpapi – HttpApi Plugin for Fortinet FortiOS Appliance or VM

> **Note:**
>
> This httpapi plugin is part of the [fortinet.fortios collection](https://galaxy.ansible.com/fortinet/fortios) (version 2.2.1).
>
> You might already have this collection installed if you are using the `ansible` package.
> It is not included in `ansible-core`.
> To check whether it is installed, run `ansible-galaxy collection list`.
>
> To install it, use: `ansible-galaxy collection install fortinet.fortios`.
>
> To use it in a playbook, specify: `fortinet.fortios.fortios`.

New in fortinet.fortios 2.0.0
