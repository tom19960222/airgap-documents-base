# mellanox.onyx.onyx cliconf – Use onyx cliconf to run command on Mellanox ONYX platform

> **Note:**
>
> This cliconf plugin is part of the [mellanox.onyx collection](https://galaxy.ansible.com/mellanox/onyx) (version 1.0.0).
>
> You might already have this collection installed if you are using the `ansible` package.
> It is not included in `ansible-core`.
> To check whether it is installed, run `ansible-galaxy collection list`.
>
> To install it, use: `ansible-galaxy collection install mellanox.onyx`.
>
> To use it in a playbook, specify: `mellanox.onyx.onyx`.

New in mellanox.onyx 2.5

- [Synopsis](onyx_cliconf.md#synopsis)

## [Synopsis](onyx_cliconf.md#id1)

- This onyx plugin provides low level abstraction apis for sending and receiving CLI commands from Mellanox ONYX network devices.

> **Hint:**
>
> Configuration entries for each entry type have a low to high priority order. For example, a variable that is lower in the list will override a variable that is higher up.
