## [Plugin Index](index.md#id2)

These are the plugins in the community.sap collection:

### Modules

- [hana_query module](hana_query_module.md#ansible-collections-community-sap-hana-query-module) – Execute SQL on HANA
- [sap_company module](sap_company_module.md#ansible-collections-community-sap-sap-company-module) – This module will manage a company entities in a SAP S4HANA environment
- [sap_snote module](sap_snote_module.md#ansible-collections-community-sap-sap-snote-module) – This module will upload and (de)implements `SNOTES` in a SAP S4HANA environment.
- [sap_system_facts module](sap_system_facts_module.md#ansible-collections-community-sap-sap-system-facts-module) – Gathers SAP facts in a host
- [sap_task_list_execute module](sap_task_list_execute_module.md#ansible-collections-community-sap-sap-task-list-execute-module) – Perform SAP Task list execution
- [sap_user module](sap_user_module.md#ansible-collections-community-sap-sap-user-module) – This module will manage a user entities in a SAP S4/HANA environment
- [sapcar_extract module](sapcar_extract_module.md#ansible-collections-community-sap-sapcar-extract-module) – Manages SAP SAPCAR archives
