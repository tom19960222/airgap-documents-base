## [Plugin Index](index.md#id3)

These are the plugins in the community.hrobot collection:

### Modules

- [boot module](boot_module.md#ansible-collections-community-hrobot-boot-module) – Set boot configuration
- [failover_ip module](failover_ip_module.md#ansible-collections-community-hrobot-failover-ip-module) – Manage Hetzner’s failover IPs
- [failover_ip_info module](failover_ip_info_module.md#ansible-collections-community-hrobot-failover-ip-info-module) – Retrieve information on Hetzner’s failover IPs
- [firewall module](firewall_module.md#ansible-collections-community-hrobot-firewall-module) – Manage Hetzner’s dedicated server firewall
- [firewall_info module](firewall_info_module.md#ansible-collections-community-hrobot-firewall-info-module) – Manage Hetzner’s dedicated server firewall
- [reset module](reset_module.md#ansible-collections-community-hrobot-reset-module) – Reset a dedicated server
- [reverse_dns module](reverse_dns_module.md#ansible-collections-community-hrobot-reverse-dns-module) – Set or remove reverse DNS entry for IP
- [server module](server_module.md#ansible-collections-community-hrobot-server-module) – Update server information
- [server_info module](server_info_module.md#ansible-collections-community-hrobot-server-info-module) – Query information on one or more servers
- [ssh_key module](ssh_key_module.md#ansible-collections-community-hrobot-ssh-key-module) – Add, remove or update SSH key
- [ssh_key_info module](ssh_key_info_module.md#ansible-collections-community-hrobot-ssh-key-info-module) – Query information on SSH keys
