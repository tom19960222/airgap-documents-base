These are the plugins in the community.proxysql collection:

### Modules

- [proxysql_backend_servers module](proxysql_backend_servers_module.md#ansible-collections-community-proxysql-proxysql-backend-servers-module) – Adds or removes mysql hosts from proxysql admin interface
- [proxysql_global_variables module](proxysql_global_variables_module.md#ansible-collections-community-proxysql-proxysql-global-variables-module) – Gets or sets the proxysql global variables
- [proxysql_info module](proxysql_info_module.md#ansible-collections-community-proxysql-proxysql-info-module) – Gathers information about proxysql server
- [proxysql_manage_config module](proxysql_manage_config_module.md#ansible-collections-community-proxysql-proxysql-manage-config-module) – Writes the proxysql configuration settings between layers
- [proxysql_mysql_users module](proxysql_mysql_users_module.md#ansible-collections-community-proxysql-proxysql-mysql-users-module) – Adds or removes mysql users from proxysql admin interface
- [proxysql_query_rules module](proxysql_query_rules_module.md#ansible-collections-community-proxysql-proxysql-query-rules-module) – Modifies query rules using the proxysql admin interface
- [proxysql_query_rules_fast_routing module](proxysql_query_rules_fast_routing_module.md#ansible-collections-community-proxysql-proxysql-query-rules-fast-routing-module) – Modifies query rules for fast routing policies using the proxysql admin interface
- [proxysql_replication_hostgroups module](proxysql_replication_hostgroups_module.md#ansible-collections-community-proxysql-proxysql-replication-hostgroups-module) – Manages replication hostgroups using the proxysql admin interface
- [proxysql_scheduler module](proxysql_scheduler_module.md#ansible-collections-community-proxysql-proxysql-scheduler-module) – Adds or removes schedules from proxysql admin interface
