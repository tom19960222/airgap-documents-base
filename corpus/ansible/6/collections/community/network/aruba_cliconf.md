# community.network.aruba cliconf – Use aruba cliconf to run command on Aruba platform

> **Note:**
>
> This cliconf plugin is part of the [community.network collection](https://galaxy.ansible.com/community/network) (version 4.0.2).
>
> You might already have this collection installed if you are using the `ansible` package.
> It is not included in `ansible-core`.
> To check whether it is installed, run `ansible-galaxy collection list`.
>
> To install it, use: `ansible-galaxy collection install community.network`.
>
> To use it in a playbook, specify: `community.network.aruba`.

- [Synopsis](aruba_cliconf.md#synopsis)

## [Synopsis](aruba_cliconf.md#id1)

- This aruba plugin provides low level abstraction apis for sending and receiving CLI commands from Aruba network devices.
