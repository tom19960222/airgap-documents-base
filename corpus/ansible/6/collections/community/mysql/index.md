These are the plugins in the community.mysql collection:

### Modules

- [mysql_db module](mysql_db_module.md#ansible-collections-community-mysql-mysql-db-module) – Add or remove MySQL databases from a remote host
- [mysql_info module](mysql_info_module.md#ansible-collections-community-mysql-mysql-info-module) – Gather information about MySQL servers
- [mysql_query module](mysql_query_module.md#ansible-collections-community-mysql-mysql-query-module) – Run MySQL queries
- [mysql_replication module](mysql_replication_module.md#ansible-collections-community-mysql-mysql-replication-module) – Manage MySQL replication
- [mysql_role module](mysql_role_module.md#ansible-collections-community-mysql-mysql-role-module) – Adds, removes, or updates a MySQL role
- [mysql_user module](mysql_user_module.md#ansible-collections-community-mysql-mysql-user-module) – Adds or removes a user from a MySQL database
- [mysql_variables module](mysql_variables_module.md#ansible-collections-community-mysql-mysql-variables-module) – Manage MySQL global variables
