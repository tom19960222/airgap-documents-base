# GraphQL API Parameters

## GRAPHQL_ENABLED

!!! tip "Dynamic Configuration Parameter"

Default: `True`

Setting this to False will disable the GraphQL API.

---

## GRAPHQL_MAX_ALIASES

Default: `10`

The maximum number of queries that a GraphQL API request may contain.
