**Requirements:**

* Kubernetes must be configured to use CNI (see [Network Plugin Requirements](https://kubernetes.io/docs/concepts/extend-kubernetes/compute-storage-net/network-plugins/#network-plugin-requirements))
* Linux kernel >= 5.4
