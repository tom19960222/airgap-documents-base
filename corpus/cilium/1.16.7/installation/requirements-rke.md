To install Cilium top of a **standalone** [Rancher Kubernetes Engine 1 (RKE1)](https://rke.docs.rancher.com/)
or [Rancher Kubernetes Engine 2 (RKE2)](https://docs.rke2.io/) cluster,
follow the installation instructions provided in the dedicated
[Installation using Rancher Kubernetes Engine](k8s-install-rke.md#rke_install) guide.

If your RKE1/2 cluster is managed by Rancher (**non-standalone**), follow the
[Installation using Rancher](k8s-install-rancher-existing-nodes.md#rancher_managed_rke_clusters) guide instead.
