Ztunnel refers to the node proxy component of [ambient](index.md#ambient) data plane mode.
Ztunnel runs on each node and securely transmits traffic using the [HBONE](index.md#hbone) protocol.

For more details, see [ambient data plane documentation](../../ambient/architecture/data-plane/index.md)
