A sidecar, generally, is a container that runs alongside a primary application to provide additional functionality.
In Istio, sidecar mode is a [data plane mode](index.md#data-plane-mode) that runs an [Envoy](index.md#envoy) proxy alongside each
[Pod](index.md#pod).
