# Improving search performance

OpenSearch offers several ways to improve search performance:

- Run resource-intensive queries asynchronously with [asynchronous search](../async/index.md).

- Search segments concurrently using [concurrent segment search](../concurrent-segment-search/index.md).

- Improve aggregation performance using a [star-tree index](../star-tree-index/index.md).
