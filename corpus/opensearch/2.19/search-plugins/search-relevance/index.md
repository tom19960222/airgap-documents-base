# Search relevance

Search relevance evaluates the accuracy of the search results returned by a query. The higher the relevance, the better the search engine.

OpenSearch provides the following search relevance features:

- [Comparing search results](compare-search-results/index.md) from two queries side by side in OpenSearch Dashboards.

- [Reranking search results](reranking-search-results/index.md) using a cross-encoder reranker.

- [Query rewriting](query-rewriting/index.md).
