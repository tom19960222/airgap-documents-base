# Tools
**Introduced 2.13**
{: .label .label-purple }

A _tool_ performs a set of specific tasks. The following table lists all tools that OpenSearch supports.

Specify a tool by providing its `type`, `parameters`, and, optionally, a `description`. For example, you can specify an `AgentTool` as follows:

```json
{
  "type": "AgentTool",
  "description": "A general agent to answer any question",
  "parameters": {
    "agent_id": "9X7xWI0Bpc3sThaJdY9i"
  }
}
```

Each tool takes a list of parameters specific to that tool. In the preceding example, the `AgentTool` takes an `agent_id` of the agent it will run. For a list of parameters, see each tool's documentation.

|Tool	| Description	|
|:---	|:---	|
|[`AgentTool`](agent-tool/index.md)	|Runs any agent. |
|[`CatIndexTool`](cat-index-tool/index.md)	|Retrieves index information for the OpenSearch cluster. |
|[`ConnectorTool`](connector-tool/index.md)	| Uses a [connector](../../remote-models/connectors/index.md) to call any REST API function. |
|[`IndexMappingTool`](index-mapping-tool/index.md)	|Retrieves index mapping and setting information for an index. |
|[`CreateAnomalyDetectorTool`](create-anomaly-detector/index.md)	| Enables an LLM to suggest required parameters for creating an anomaly detector. |
|[`MLModelTool`](ml-model-tool/index.md)	|Runs machine learning models.	|
|[`NeuralSparseSearchTool`](neural-sparse-tool/index.md)	| Performs sparse vector retrieval. |
|[`PPLTool`](ppl-tool/index.md)	|Translates natural language into a Piped Processing Language (PPL) query.	|
|[`RAGTool`](rag-tool/index.md)	|Uses neural search or neural sparse search to retrieve documents and integrates a large language model to summarize the answers. |
|[`SearchAlertsTool`](search-alerts-tool/index.md)	|Searches for alerts.	|
|[`SearchAnomalyDetectorsTool`](search-anomaly-detectors/index.md)	| Searches for anomaly detectors.	|
|[`SearchAnomalyResultsTool`](search-anomaly-results/index.md)	| Searches anomaly detection results generated by anomaly detectors.	|
|[`SearchIndexTool`](search-index-tool/index.md)	|Searches an index using a query written in query domain-specific language (DSL). |
|[`SearchMonitorsTool`](search-monitors-tool/index.md)	| Searches for alerting monitors.	|
|[`VectorDBTool`](vector-db-tool/index.md)	|Performs dense vector retrieval.	|
|[`VisualizationTool`](visualization-tool/index.md)	|Finds visualizations in OpenSearch Dashboards.	|

## Developer information

The agents and tools framework offers flexibility and extensibility. See the [tools library](https://github.com/opensearch-project/skills/tree/main/src/main/java/org/opensearch/agent/tools) for OpenSearch-provided tools. Implement the [**Tool** interface](https://github.com/opensearch-project/ml-commons/blob/2.x/spi/src/main/java/org/opensearch/ml/common/spi/tools/Tool.java) to build custom tools for different use cases.
