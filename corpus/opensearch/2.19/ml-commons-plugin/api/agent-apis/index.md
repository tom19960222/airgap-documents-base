# Agent APIs
**Introduced 2.13**
{: .label .label-purple }

You can automate machine learning (ML) tasks using agents and tools. An _agent_ orchestrates and runs ML models and tools. For more information, see [Agents and tools](../../agents-tools/index.md).

ML Commons supports the following agent-level APIs:

- [Register agent](register-agent/index.md)
- [Execute agent](execute-agent/index.md)
- [Get agent](get-agent/index.md)
- [Search agent](search-agent/index.md)
- [Delete agent](delete-agent/index.md)
