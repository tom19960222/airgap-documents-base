# Ingest APIs
**Introduced 1.0**
{: .label .label-purple }

Ingest APIs are a valuable tool for loading data into a system. Ingest APIs work together with [ingest pipelines](../../ingest-pipelines/index.md) and [ingest processors](../../ingest-pipelines/processors/index-processors/index.md) to process or transform data from a variety of sources and in a variety of formats.

## Ingest pipeline APIs

Simplify, secure, and scale your OpenSearch data ingestion with the following APIs:

- [Create pipeline](../../ingest-pipelines/create-ingest/index.md): Use this API to create or update a pipeline configuration.
- [Get pipeline](../../ingest-pipelines/get-ingest/index.md): Use this API to retrieve a pipeline configuration.
- [Simulate pipeline](../../ingest-pipelines/simulate-ingest/index.md): Use this pipeline to test a pipeline configuration.
- [Access data in a pipeline](../../ingest-pipelines/accessing-data/index.md): Use this API to access data in a pipeline.
- [Delete pipeline](../../ingest-pipelines/delete-ingest/index.md): Use this API to delete a pipeline configuration.
