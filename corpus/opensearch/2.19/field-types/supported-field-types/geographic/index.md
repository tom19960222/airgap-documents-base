# Geographic field types

Geographic fields contain values that represent points or shapes on a map. The following table lists all geographic field types that OpenSearch supports.

Field data type | Description
:--- | :---
[`geo_point`](../geo-point/index.md) | A geographic point specified by latitude and longitude.
[`geo_shape`](../geo-shape/index.md) | A geographic shape, such as a polygon or a collection of geographic points.
