# The virtualization API

# Introduction

The libvirt project:

- is a toolkit to manage [virtualization platforms](platforms.md)
- is accessible from C, Python, Perl, Go and more
- is licensed under open source licenses
- supports
  [KVM](drvqemu.md),
  [Hypervisor.framework](drvqemu.md),
  [QEMU](drvqemu.md),
  [Xen](drvxen.md),
  [Virtuozzo](drvvirtuozzo.md),
  [VMware ESX](drvesx.md),
  [LXC](drvlxc.md),
  [BHyve](drvbhyve.md) and
  [more](drivers.md)
- targets Linux, FreeBSD, [Windows](windows.md) and [macOS](macos.md)
- is used by many [applications](apps.md)

Recent / forthcoming [release changes](https://libvirt.org/news.html)
